## OpenWeatherMap

WhereWeather fetches weather data from OpenWeatherMap.
Users must provide their own OpenWeatherMap API key.

Do not commit or publish a real `openweather_api_key.bat` file.
Only `openweather_api_key.example.bat` should be shared.

OpenWeatherMap terms and API details are available from OpenWeather:

- https://openweathermap.org/api
